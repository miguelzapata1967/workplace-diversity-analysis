# Workplace Diversity Analysis

**Miguel Angel Zapata | Data Engineering Academy learning project**

This project examines workforce representation, compensation, education, experience, and management structure using two related employee datasets. Its purpose is to identify descriptive patterns and questions for further investigation.

## Project Context & AI Assistance

This is an Academy learning exercise developed with substantial AI assistance. ChatGPT/Codex helped inspect the data, generate Python code, perform calculations, and prepare interpretations and documentation. My participation includes running the code, asking questions, reviewing outputs, and studying the reasoning behind the analysis. The work documents my developing analytical skills; I do not present all generated code or calculations as independently developed work.

The datasets contain 10,000 employees each and join one-to-one on `employee_id`. Source CSVs remain unchanged. Dataset provenance, salary currency/period, and the signing-bonus definition require confirmation.

The analysis describes associations. It does not establish discrimination, causation, or promotion rates.
